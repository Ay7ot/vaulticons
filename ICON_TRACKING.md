# Icon Tracking

This document tracks the design and implementation status of all icons for the VaultIcons library.

**Status Legend:**
*   `Planned`: Icon is listed but not yet started.
*   `In Design`: Icon is currently being designed in Figma/Illustrator.
*   `Designed`: SVG design is complete.
*   `Implemented`: React component created and tested.
*   `Needs Review`: Ready for final review before merging.
*   `Done`: Icon is complete and merged.
